# Dungeon Browser: Alison

A retro pixel-art escape-room RPG built with [Pyxel](https://github.com/kitao/pyxel), inspired by *Dungeon Crawler Carl*.

Alison Gretz wakes up to find her house has been inducted into "The Browser" — a sentient dungeon
system that has scattered her family across escalating rooms. She has to puzzle her way through
the kitchen, garage, library, and server room to find her husband, her math-wizard skateboarder
son Liam (13), and her fun-loving daughter Maisie (6).

## Rooms

1. **The Kitchen** — Intro + tutorial. Coffee, a book, and the fridge.
2. **The Garage** — Find Liam. Math, skateboards, and memory.
3. **The Library** — Find Maisie. Colors, shapes, and a hidden bookmark.
4. **The Server Room** — Find the husband. Final puzzle using items from every prior room.

## Running

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

Press **Q** to quit, **arrow keys** to move, **Z** to interact, **X** to open inventory.
